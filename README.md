# Simple Frontend-Based E-commerce Site README

https://umarbellokanwa.github.io/shopark-/ (mobile view)

## Introduction
This is a simple e-commerce site built entirely using frontend technologies. It allows users to browse products, add items to a shopping cart, and proceed to checkout. The site is designed for small-scale online stores and can be easily customized to fit various product categories.

## Features
1. **Product Listing**
   - Displays a variety of products with images, descriptions, and prices.
   - Search for products

2. **Shopping Cart**
   - Users can add or remove items from the cart and view the total price.

3. **Checkout**
   - A simple checkout process to simulate order placement.

4. **Responsive Design**
   - Optimized for both desktop and mobile devices.

5. **User-Friendly Interface**
   - Intuitive design to ensure a smooth user experience.

## Technology Stack
- **Frontend**: HTML, CSS, JavaScript

## Prerequisites
Ensure you have a modern web browser installed.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/UmarBelloKanwa/shopark
   cd simple-ecommerce-site
   ```
2. Open the `index.html` file in your browser:
   ```bash
   open index.html  # For Linux/macOS
   start index.html  # For Windows
   ```

## Usage
1. **Browse Products**: Navigate through the product listings.
2. **Add to Cart**: Click on the **Add to Cart** button to add products to your cart.
3. **View Cart**: Click on the cart icon to view items added.
4. **Checkout**: Click on the **Checkout** button to simulate placing an order.

## Key Functionalities
- Dynamic product listing with JavaScript.
- Basic cart management system.
- Responsive design for different screen sizes.
